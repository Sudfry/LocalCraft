界面没能启动

本地服务的地址能打开，但页面脚本没有跑起来。常见原因和解决办法：

  1. 系统代理拦住了 127.0.0.1（装了 Clash / v2ray / 各类加速器时最常见）。
    请在代理软件里把 127.0.0.1 和 localhost 加入直连（绕过）列表， 或临时关掉系统代理后点下面的按钮重新加载。
  2. 主程序已经退出。重新双击 LocalCraft.exe，再刷新本页。
  3. 浏览器内核太旧。本界面需要 Chromium 内核（Edge / Chrome）， 不支持 IE 模式和部分国产浏览器的兼容模式。
